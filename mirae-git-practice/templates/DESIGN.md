## 1. 요구사항

> **기능 요구사항** = "무엇을 하는가"  ·  **비기능 요구사항** = "얼마나 잘해야 하는가"
> **우선순위(MoSCoW)** — Must(없으면 출시 불가) / Should(중요) / Could(있으면 좋음) / Won't(이번엔 안 함)
>
> 아래 R1~R3 예시를 참고해 **본인 것으로 바꿔** 쓰세요. Must 2개 + Should 1개가 목표입니다.

| ID | 사용자 요구 | 유형 | 우선순위 |
| --- | --- | --- | --- |
| R1 | 도시를 검색하면 현재 날씨를 본다 | 기능 | Must |
| R2 | 결과가 3초 안에 표시된다 | 비기능 | Must |
| R3 | 최근 검색한 도시를 다시 선택한다 | 기능 | Should |
